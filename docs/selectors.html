📋 Overview

The ChatGPT Codex UI (https://chatgpt.com/codex/) uses React with dynamically generated class names. This means CSS class selectors are fragile and will break between deployments.

⚠️ Warning: Prefer selectors in this order of stability:
  1. aria-label - Most stable (accessibility attributes rarely change)
  2. data-testid - Stable when present (intended for testing)
  3. name attribute - Fairly stable for form elements
  4. Semantic element combinations - e.g. button:has-text("Submit")
  5. CSS classes - Avoid! Generated names like .css-1a2b3c change frequently

💬 Prompt Input

The main text input for entering Codex task prompts.

Selector Type Stability Notes
.ProseMirror class Recommended The visible contenteditable editor. ProseMirror is the library name, unlikely to change.
[contenteditable="true"] attr Stable Generic but reliable. May match multiple elements.
textarea[name="prompt-textarea"] name Stable Hidden textarea that syncs with ProseMirror. May not be visible.
#prompt-textarea id Stable Hidden textarea by ID.
Playwright - Type in prompt
// Best approach - use ProseMirror editor directly
const editor = page.locator('.ProseMirror');
await editor.click();
await page.keyboard.type('Add unit tests for the auth module');

// Alternative - fill hidden textarea
await page.fill('textarea[name="prompt-textarea"]', 'Your prompt here');
💡 Tip: ProseMirror is a contenteditable div, not a real textarea. Use keyboard.type() instead of fill() for more reliable input.

🚀 Submit Button

The button to submit a prompt and create a new task.

Selector Type Stability Notes
button[aria-label="Submit"] aria Recommended Most reliable - accessibility labels are stable.
button[data-testid="send-button"] testid Stable Test ID if present. Check current page.
button:has(svg) structure Fragile The submit button contains an arrow SVG icon.
Playwright - Submit prompt
// Click submit button
await page.click('button[aria-label="Submit"]');

// Alternative: press Enter in the editor
await page.keyboard.press('Enter');

// Or Ctrl+Enter for explicit submit
await page.keyboard.press('Control+Enter');

📝 Task List

The sidebar/main area showing list of tasks.

Selector Type Stability Notes
a[href^="/codex/tasks/"] href Recommended Links to individual tasks. The href pattern is stable.
[data-testid="task-item"] testid Stable Individual task item if testid present.
nav a[href="/codex/"] href Stable Link back to task list from detail view.
Playwright - Get task list
// Get all task links
const taskLinks = await page.locator('a[href^="/codex/tasks/"]').all();

// Extract task IDs
for (const link of taskLinks) {
    const href = await link.getAttribute('href');
    const taskId = href.split('/tasks/')[1];
    const title = await link.textContent();
    console.log(`${taskId}: ${title}`);
}

// Click on first task
await page.click('a[href^="/codex/tasks/"]:first-child');

🎭 Complete Playwright Examples

Full task creation flow
import { chromium } from 'playwright';

async function createCodexTask(prompt: string) {
    const browser = await chromium.launch({ headless: false });
    const context = await browser.newContext();
    
    // Load cookies from your session
    await context.addCookies(yourCookies);
    
    const page = await context.newPage();
    await page.goto('https://chatgpt.com/codex/');
    
    // Wait for editor to load
    await page.waitForSelector('.ProseMirror');
    
    // Type the prompt
    const editor = page.locator('.ProseMirror');
    await editor.click();
    await page.keyboard.type(prompt);
    
    // Submit
    await page.click('button[aria-label="Submit"]');
    
    // Wait for task to appear
    await page.waitForSelector('a[href^="/codex/tasks/"]');
    
    // Get the new task link
    const taskLink = await page.locator('a[href^="/codex/tasks/"]').first();
    const taskUrl = await taskLink.getAttribute('href');
    const taskId = taskUrl?.split('/tasks/')[1];
    
    console.log(`Created task: ${taskId}`);
    
    await browser.close();
    return taskId;
}
Intercept API requests
// Route interception to capture task creation request
await page.route('**/backend-api/wham/tasks', async (route) => {
    const request = route.request();
    
    if (request.method() === 'POST') {
        const postData = request.postDataJSON();
        console.log('Task creation payload:', postData);
        
        // Continue with original request
        await route.continue();
    } else {
        await route.continue();
    }
});

// Or capture response
page.on('response', async (response) => {
    if (response.url().includes('/wham/tasks') && 
        response.request().method() === 'POST') {
        const body = await response.json();
        console.log('Created task:', body);
    }
});
Wait for task completion
// Wait for task to show "completed" state
await page.waitForFunction(() => {
    const status = document.querySelector('[data-status]');
    return status?.getAttribute('data-status') === 'completed';
}, { timeout: 120000 });

// Or poll the API directly
async function waitForTaskComplete(taskId: string) {
    while (true) {
        const resp = await fetch(
            `https://chatgpt.com/backend-api/wham/tasks/${taskId}`,
            { headers: { 'Authorization': `Bearer ${token}` }}
        );
        const task = await resp.json();
        
        if (task.status === 'completed') {
            return task;
        }
        await new Promise(r => setTimeout(r, 5000));
    }
}
